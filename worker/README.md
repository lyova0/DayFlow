# ИИ-меню через Gemini (бесплатно)

Ключ Gemini нельзя хранить в приложении — его увидит любой. Поэтому запросы идут через маленький Cloudflare Worker (бесплатный тариф): ключ лежит только в нём, а Worker пропускает запросы только от вошедших пользователей.

## Где создавать Worker

Worker создаётся не в приложении, а на сайте Cloudflare (бесплатный аккаунт):

1. Зарегистрируйтесь на https://dash.cloudflare.com (карта не нужна).
2. В левом меню: **Workers & Pages** → **Create** → **Create Worker** → **Deploy**.
3. На странице Worker нажмите **Edit code**, удалите весь код в окне, вставьте содержимое файла `worker.js` из этой папки и нажмите **Deploy**.
4. Адрес Worker вида `https://имя.аккаунт.workers.dev` показан вверху страницы — он понадобится в шаге 4 ниже.

## Шаги

1. **Ключ Gemini:** https://aistudio.google.com/apikey → Create API key. Бесплатный уровень не требует карты; лимиты смотрите в AI Studio.
2. **Worker:** создайте его, как описано выше («Где создавать Worker»).
3. **Переменные:** Worker → Settings → Variables and Secrets:
   - `GEMINI_API_KEY` — тип **Secret**, ваш ключ Gemini;
   - `FIREBASE_API_KEY` — значение `apiKey` из `js/config.js`;
   - `ALLOWED_ORIGIN` — необязательно, адрес сайта (например `https://name.github.io`, без слэша на конце);
   - `GEMINI_MODEL` — необязательно; по умолчанию `gemini-2.5-flash`. Если Gemini вернёт ошибку модели, возьмите актуальное название в AI Studio.
4. **Адрес Worker** (вида `https://имя.аккаунт.workers.dev`) вставьте в `js/config.js` вместо `YOUR_WORKER_URL`.
5. В приложении: Питание → План → «Составить меню». Нужно войти в аккаунт.

## Что отправляется в Gemini

Только названия продуктов из холодильника, срок (1 или 7 дней) и ваши пожелания. По условиям бесплатного тарифа Google может использовать запросы для улучшения своих продуктов, поэтому личные данные в пожелания не пишите.
